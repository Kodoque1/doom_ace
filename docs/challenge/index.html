Doomception · your turn

The challenge

Several copies of a tiny Doom share one 64 KiB machine, with no operating system to help. Write the scheduler that keeps them from trampling each other.

Everything below is the kit's own C, compiled to WebAssembly: the same compiler, assembler, machine and checker as make check, so the verdicts are the same. Background: the Doomception article. Rules and the local kit: sandbox/README.md.
